# Architecture specifications

`system-overview.md` defines the runtime components; `data-flow.md` traces commands and evidence through the system; `storage-and-evidence.md` defines private file handling; `audit-and-provenance.md` defines history and attribution; `queue-and-idempotency.md` sets retry/worker guarantees; `decisions-and-adr.md` records selected MVP tradeoffs. Security-sensitive changes should update the threat model and tests alongside architecture docs.
