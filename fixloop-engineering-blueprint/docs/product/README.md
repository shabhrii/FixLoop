# Product specification

`PRD.md` defines user need and intended outcomes; `mvp-scope.md` distinguishes first-release behavior from deferred features; `user-roles-and-permissions.md` maps actors to capabilities; `workflow-and-state-machine.md` defines allowed lifecycle transitions and closure guards; `acceptance-criteria.md` expresses testable outcomes. When requirements conflict, raise a decision record rather than silently weakening evidence, human review or tenant isolation.
